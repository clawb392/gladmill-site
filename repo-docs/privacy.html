Privacy policy for Repo Docs: OpenAPI & Markdown from Git

Last updated 2026-10-04

Repo Docs: OpenAPI & Markdown from Git ("the app") is provided by Gladmill and runs on Atlassian Forge, Atlassian's cloud platform for apps.

What the app stores

  • Macro settings you enter (Git provider, repository, branch and file path), saved in your Confluence page by Confluence.
  • Access tokens your site admin adds, in Atlassian's encrypted Forge app storage for your site.

The app does not store file contents, page contents or personal data, and uses no analytics, cookies or tracking.

Where data goes

To show a file, the app's backend sends the repository, file path, branch or tag, and your site's token to the Git host you chose (GitHub, Bitbucket or GitLab.com) and returns the file to the page. Badge images from img.shields.io or badgen.net referenced in a Markdown file are loaded by the viewer's browser. Apart from these, nothing is sent anywhere else.

Logs

When a fetch fails, the app logs the provider, the HTTP status, whether a token was set and, for GitHub, its request id and the permission the request needed, for support. Logs never contain tokens or file contents and are kept by Atlassian's Forge logging.

Deletion

Admins can remove a token at any time in the app's settings. When the app is uninstalled, Atlassian soft-deletes its stored tokens and permanently deletes them after Atlassian's standard retention period; if you reinstall within 21 days, Atlassian can restore them on request. Macro settings stay in your pages until you remove the macros.
