Repo Docs: OpenAPI & Markdown from Git

Two macros that render files from Git repositories in Confluence Cloud: OpenAPI Docs (OpenAPI 3.x and Swagger 2.0 specs) and Markdown from Git (Markdown with Mermaid diagrams and repo images). Files are fetched by the app's backend on every page view, so pages follow the branch or tag you choose.

Confluence Cloud app

Free for up to 10 users. Show OpenAPI specs and Markdown from private GitHub, Bitbucket and GitLab repos in Confluence, always from the branch or tag you choose.

Get Repo DocsAsk a question

1. Add a read-only token (site admins, private repos only)

Go to Settings → OpenAPI Docs and save one token per Git host. The token is stored in Atlassian's encrypted app storage and is never shown to page viewers or editors.

  • GitHub: a fine-grained personal access token limited to the repos that hold your docs, with Contents: Read-only.
  • Bitbucket Cloud: a repository or workspace access token with Repositories: Read.
  • GitLab.com: a project or group access token with read_repository (or read_api).

Use tokens that can only read the repositories you want shown: anyone who can edit a page can display any OpenAPI or Markdown file those tokens can read.

2. Insert a macro

Edit a page, type /OpenAPI Docs or /Markdown from Git, then choose the provider, repository (owner/repo, workspace/repo or group/project), file path and branch, tag or commit.

What gets rendered

  • OpenAPI Docs: .yaml, .yml or .json files that are OpenAPI or Swagger documents, up to 2 MB. Other YAML/JSON files are refused.
  • Markdown from Git: .md or .markdown, up to 1 MB. Mermaid code blocks become diagrams; relative images load from the same repo (up to 1 MB each); relative links open the file on your Git host. Badges from img.shields.io and badgen.net display; other external images are blocked by Atlassian's content policy.

Troubleshooting

  • "rejected the token": the token expired or was revoked; an admin saves a new one.
  • "can't read this repository": the token lacks access to that repo, or the host is rate-limiting.
  • "couldn't find that file": check repository, path and branch, and that the token can see the repo.
  • "licence isn't active": a site admin checks the app under Manage apps.
